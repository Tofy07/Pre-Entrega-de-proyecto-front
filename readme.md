# Mi Tienda

## Descripcion

Mi Tienda es un sitio web de venta de productos tecnologicos. Su proposito es presentar productos, mostrar sus caracteristicas y precios, y ofrecer una forma sencilla de navegar por la tienda.

## Productos

Actualmente, la pagina principal presenta:

- Auriculares inalambricos Xiaomi Redmi Buds 6 Play.
- Pendrive Lenovo USB 3.0 de 2 TB.

## Secciones del sitio

- **Inicio:** presenta la tienda y los productos disponibles.
- **Contacto:** pagina destinada a la informacion de contacto.
- **Carrito:** pagina vinculada desde los botones para anadir productos.

## Tecnologias

- HTML
- CSS
- javascrip(proximamente)

## Como ver el sitio

Abre `index.html` en un navegador web.

## Estructura del proyecto

- `index.html`: pagina principal.
- `css/styles.css`: estilos del sitio.
- `pages/contacto.html`: pagina de contacto.
- `pages/carrito.html`: pagina del carrito.
- `img/`: imagenes utilizadas en el sitio.
